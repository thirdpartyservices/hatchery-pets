# Leak Otter

keeps every rock it has ever held and never lets a single one go

![preview](preview.gif)

Install: copy this folder to `~/.codex/pets/leak-otter/` (Windows: `%USERPROFILE%\.codex\pets\`), then Codex > Settings > Appearance > Pets > refresh.
