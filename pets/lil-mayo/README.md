# Lil Mayo

A tiny grey alien who floats, judges your code, and loves mayo.

![preview](preview.gif)

Install: copy this folder to `~/.codex/pets/lil-mayo/` (Windows: `%USERPROFILE%\.codex\pets\`), then Codex > Settings > Appearance > Pets > refresh. Page: https://3ps.online/pets/p/lil-mayo.html
