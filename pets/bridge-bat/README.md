# Bridge Bat

dials into the conference call, stays silent, and brings back the recording

![preview](preview.gif)

Install: copy this folder to `~/.codex/pets/bridge-bat/` (Windows: `%USERPROFILE%\.codex\pets\`), then Codex > Settings > Appearance > Pets > refresh.
