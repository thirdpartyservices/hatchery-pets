# Hoop Hamster

stitches one orange square at a time and never skips a row

![preview](preview.gif)

Install: copy this folder to `~/.codex/pets/hoop-hamster/` (Windows: `%USERPROFILE%\.codex\pets\`), then Codex > Settings > Appearance > Pets > refresh.
